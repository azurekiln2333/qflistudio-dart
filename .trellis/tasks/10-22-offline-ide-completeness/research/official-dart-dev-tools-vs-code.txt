Tools chevron_right Visual Studio Code Visual Studio Code You can use VS Code to develop Dart apps. more_vert content_copy Copy link docs View source bug_report Report issue To develop Dart apps, install Visual Studio Code (VS Code) and add the Dart extension . Install VS Code # To install the latest version of VS Code , follow Microsoft's instructions for the relevant platform: Install on macOS Install on Windows Install on Linux Install the VS Code Dart extension # The Dart extension for VS Code supports Dart-specific development capabilities. These include syntax highlighting, package resolution, hot reload, and others. Launch VS Code . Click Extensions in the Activity Bar . You can also press Cmd/Ctrl + Shift + X . In the Search box, type Dart . The first extension returned should be the Dart extension . Click Install . To review the full list of features, consult the extension documentation .
