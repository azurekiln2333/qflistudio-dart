# 受控中文

本规范适用于中文技术文本。
改写时保留原文的置信度。

## 写作规则

- 一句只写一个动作。
- 使用主动语态。
- 同一概念只用一个术语。
- 不用分号连接动作。
- 每条指令最多 25 字。
- 每句说明最多 40 字。
- 删除虚动词后的名词化表达。
- 删除套话。
- 删除营销形容词。
- 用具体对象替换含糊词。
- 保留原文中的情态词。
- 不把可能性改成确定事实。

虚动词示例是 `进行` 和 `加以`。
套话示例是 `需要注意的是`。
营销词示例是 `无缝` 和 `赋能`。
含糊词示例是 `若干` 和 `一些`。
情态词示例是 `可能` 和 `也许`。

## 机械检查

先运行检查器。

```powershell
python scripts/ste-lint-zh.py README.md README.zh-Hant.md
```

检查纯指令文本时使用 25 字上限。

```powershell
python scripts/ste-lint-zh.py --max-chars 25 <文件>
```

修改检查器后运行内置自检。

```powershell
python scripts/ste-lint-zh.py --selftest
```

检查器只依赖 Python 标准库。
硬违规超过基线时返回非零退出码。
建议项只输出提示。
新文档使用默认的零基线。

## 人工复核

检查器不能代替人工复核。
复核者逐句检查动作和术语。
复核者检查原文的情态词。
复核者检查繁体中文用词。
复核者区分代码和技术说明。
机械检查通过不证明事实正确。
